# PriGI.PRS

LN-Specific Polygenic Risk Score Calculator

## Description
PriGI-PRS is a prioritized-gene-informed polygenic risk scoring framework, initially developed and validated for lupus nephritis using prioritized genes derived from LN GWAS.

## Installation

```r
# Install from GitHub
# install.packages("devtools")
devtools::install_github("username/PriGI.PRS")
```

## Usage


- Calculate LN-specific PRS scores
- Support for multiple SNP weight sets
